     3→## Project Overview
     4→Migrating and extending the Vitrual-lab-V2 project (https://github.com/Jing0715-fer/Vitrual-lab-V2) into the current Next.js 16 sandbox. The goal is to:
     5→1. Keep original functionality (agents, team/individual meetings, discussion transcripts, notes, chat, bio-tools)
     6→2. Fix UI overlap issues: REMOVE the VLM score section from meeting records AND history (it overlaps with the transcript). Redesign for a comfortable UX.
     7→3. Integrate RFdiffusion, RFantibody, ProteinMPNN, Rosetta so users can run them directly from the web UI (params, presets, run records, link to locally installed conda/WSL environments and launch from there).
     8→4. Give agents the ability to call these computational tools AND online bioinformatics APIs (BLAST, RCSB, UniProt, PubMed).
