     1→# Foundry Lab — Worklog
     2→
     3→## Project Goal
     4→Merge `foundry-ui` (protein-design job toolkit) + `Vitrual-lab-V2` (multi-agent research workspace),
     5→enhance the agent layer, preserve manual task submission, and redesign the UI as a cryoflow-style
     6→workflow canvas. Then e2e-test everything, push to a new GitHub repo, and schedule a 15-min
     7→webDevReview cron.
     8→
     9→## Architecture Decision
    10→**Product = "Foundry Lab"** — an agentic research workflow studio.
    11→- One single-page Next.js 16 app at `/`.
    12→- Center = cryoflow-style workflow canvas (custom SVG + HTML, dot-grid, port-aware edges,
    13→  optimistic mutations, two-tier inspector). No react-flow library.
    14→- Node types (catalog): Agent, Task (manual submit), TeamMeeting, IndividualMeeting, Research,
    15→  CompTool (RFdiffusion / ProteinMPNN / Rosetta / RFantibody), BioTool (BLAST / PDB / PubMed / UniProt),
    16→  Output/Report.
    17→- Enhanced agent layer: agent personas (knowledge config + system prompt), tool-calling loop
    18→  (up to 5 rounds, parallel bio+comp tool calls, fenced-block protocol), workflow-integrated
    19→  (connecting agents in canvas => a meeting; running workflow => topological DAG execution).
    20→- Manual task submission preserved: dedicated forms for agent chat, tool run, meeting create.
    21→- LLM via `z-ai-web-dev-sdk` (already a dep). Live updates via socket.io mini-service (job-events).
    22→
    23→## Repo references (research complete)
    24→- foundry-ui: job/queue substrate, designers, pipeline builder, live logs, socket.io mini-service.
    25→- Vitrual-lab-V2: Agent model + knowledge config, team/individual meetings, research pipeline,
    26→  comp tools (RFdiffusion/RFantibody/ProteinMPNN/Rosetta), bio tools (BLAST/PDB/PubMed/UniProt),
    27→  text-based tool-calling protocol (```tool / ```bio fences).
    28→- cryoflow: hand-rolled canvas (viewport transform, EdgesLayer SVG, JobCard, palette, inspector),
    29→  Cryo Ice / Deep Ice OKLCH theme, dot-grid, optimistic edges, two-tier inspector.
